# Musika Android Releases

Public distribution repository for the Musika Android application.

- **Application ID:** `com.aistudio.musikafoodhub.fmpqkx`
- **Minimum Android version:** Android 7.0 (API 24)
- **Download:** Open the [latest release](https://github.com/TakudzwaDavidMakumbe/musika-android-releases/releases/latest) and download the APK asset.
- **Update metadata:** [latest.json](https://github.com/TakudzwaDavidMakumbe/musika-android-releases/releases/latest/download/latest.json) (published with each release).

## Install and update

1. Download the APK from a release.
2. Open it on your Android device and approve installation when Android prompts you.
3. For updates, install a newer release over the existing app. Keep the app installed; uninstalling may remove local app data.

Android requires the user to approve installation of app updates. The app's updater must verify the published SHA-256 checksum before opening the Android package installer.

## Security

This repository contains public release files only. The application source code and release-signing keystore remain in the private source repository and its protected CI secrets. Never upload signing keystores, passwords, service-role keys, or other private credentials here.
